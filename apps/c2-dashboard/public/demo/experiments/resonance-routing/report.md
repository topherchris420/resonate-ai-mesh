# Routing judgment by measured agent instability

Experiment `resonance-routing`. Generated by `mesh` from `summary.json` and `runs.jsonl`. Every number is measured from recorded simulated runs; no text below was written by a model.

## Research question

Can judgment be consulted only for agents whose recent proposals were often not committed, cutting judgment calls while keeping its effect on commits made from degraded evidence?

## Hypothesis

Instability routing makes fewer judgment calls than consulting judgment on every valid proposal.

Prediction: `judgment_calls` will decrease from `judge_always` to `judge_on_instability`.

## Configuration

- Scenario: `perturbed-mesh`
- Repetitions per condition: 100 (base seed 42; repetition r uses the same derived seed in every condition)
- Manifest hash: `sha256:177619b7bbab90009bb8085b08fa873ec2f8b1e812c8fc9e3fada42285aad89b`

## Limitations

- All inputs are simulated. Results describe this simulator and kernel configuration, not people or physical systems.
- Repetitions differ only by seed; they are not independent samples of real-world conditions.
- Mock judges are deterministic rules defined in this repository, not language models.
- The routing signal is each agent's own recent rejection and withhold rate; a stale observation from a historically stable agent is not routed to judgment.

## Reproduce

```bash
mesh experiment run experiments/resonance-routing/manifest.yaml
```
