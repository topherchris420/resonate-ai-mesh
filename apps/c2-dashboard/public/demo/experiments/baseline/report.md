# Baseline reference values

Experiment `baseline`. Generated by `mesh` from `summary.json` and `runs.jsonl`. Every number is measured from recorded simulated runs; no text below was written by a model.

## Research question

Under normal operation (static hazards, no faults, no operator-load perturbation), what values do the run metrics and resonance dimensions take, and how much do they vary with the seed alone?

## Hypothesis

Without faults or perturbations, deterministic validation rejects only occasional separation conflicts, no unsafe proposal is committed, and every agent with a goal reaches it.

## Configuration

- Scenario: `baseline`
- Repetitions per condition: 30 (base seed 42; repetition r uses the same derived seed in every condition)

## Limitations

- All inputs are simulated. Results describe this simulator and kernel configuration, not people or physical systems.
- Repetitions differ only by seed; they are not independent samples of real-world conditions.
- Mock judges are deterministic rules defined in this repository, not language models.
- One fixed arena layout; seeds change only sensor noise.

## Reproduce

```bash
mesh experiment run experiments/baseline/manifest.yaml
```

Any single run can be regenerated with `mesh run experiments/baseline/manifest.yaml --condition <id> --rep <n>`; its event-log head hash must equal the `head_hash` column of `runs.csv`.
